# 📋 FormScript — جسر استيضاح متطلبات مشاريع الذكاء الاصطناعي
> **أداة ويب تفاعلية وخفيفة لتحويل أسئلة واستيضاحات الذكاء الاصطناعي إلى استبيان متصفح تفاعلي، وإعادة المحددات بدقة 100% لكتابة كود دقيق خالٍ من التخمين.**

اقرأ بلغات أخرى: [English (الإنجليزية)](./README-EN.md) | [Français (الفرنسية)](./README-FR.md) | [الدليل الرئيسي](./README.md)  
🤖 **لنماذج الذكاء الاصطناعي:** راجع [AI_INSTRUCTIONS.md](./AI_INSTRUCTIONS.md)

---

## 💡 فكرة المشروع والحل

عند طلب مشاريع برمجية من الذكاء الاصطناعي (مثل ChatGPT, Claude, Cursor, Antigravity, Copilot)، تكون النتائج أحياناً غير دقيقة بسبب نقص التفاصيل المعمارية والمتطلبات.

الإجابة على 5-10 أسئلة تقنية مع خياراتها داخل شات الدردشة التقليدي عملية بطيئة ومتعبة وغير مريحة. **FormScript** يقدم الحل الأمثل:

```
[شات الـ AI] ────(يكتب ملف الأسئلة)───> [مجلد questions/] ───> [واجهة الفورم التفاعلية]
                                                                        │
[كود دقيق 100%] <──(لصق الإجابات)──── [نسخ بنقرة واحدة] <──────(اختيار الإجابات بسهولة)
```

## ⚡ أبرز المميزات

1. **دعم تعدد اللغات (الإنجليزية هي الافتراضية، مع دعم كامل للعربية والفرنسية):**
   - يمكن التبديل فوراً بين **الإنجليزية** و**العربية (RTL)** و**الفرنسية** من واجهة الموقع، مع تعديل الاتجاه والخطوط بسلاسة.
2. **حرية لغوية كاملة في الأسئلة (بدون أي قيود):**
   - يكتشف الذكاء الاصطناعي اللغة التي تتحدث بها معه تلقائياً ويكتب الأسئلة بنفس لغتك (عربية، إنجليزية، فرنسية، وغيرها). المحلل الذكي في FormScript يدعم أي لغة في العالم.
3. **خيار «أخرى» التفاعلي:**
   - كل سؤال يحتوي دائماً على خيار (أخرى / Other). بمجرد النقر عليه، ينبثق حقل إدخال نصي أنيق لكتابة أي إجابة حرة أو متطلبات خاصة بك.
4. **مزامنة مباشرة مع مجلد `questions/`:**
   - يقرأ السيرفر الملفات الموجودة في المجلد لحظياً، فلا حاجة للنسخ واللصق إذا قام الـ AI بإنشاء الملف مباشرة.
5. **لوحة إدارة ملفات متكاملة في المتصفح:**
   - استعراض ملفات الأسئلة، تعديل النصوص وحفظها، حذف الملفات، أو لصق وإنشاء ملف جديد.
6. **نسخ النتيجة للذكاء الاصطناعي بضغطة زر واحدة:**
   - يجمع الإجابات المختارة في نص Markdown منسق وجاهز للصق في الشات فوراً.
7. **تشغيل فوري بضغطة واحدة على ويندوز (`run.bat`):**
   - يتحقق من وجود Node.js، ويثبت الحزم تلقائياً، ويشغل السيرفر، ويفتح المتصفح تلقائياً على `http://localhost:3000`.

## 🤖 سيناريو استخدام الذكاء الاصطناعي للأداة

لو كنت داخل أي مشروع مستقبلي (مثلاً مشروع `ABC`) وقلت للـ AI:
> *"أريد بناء ميزة XYZ، استخدم FormScript لتحديد المتطلبات بدقة."*

1. **الـ AI يجلب FormScript داخل مجلد المشروع:**
   ```bash
   git clone https://github.com/xlr9/FormScript.git formscript
   ```
2. **الـ AI يحدد لغتك:** إذا كنت تتحدث بالعربية، يكتب الأسئلة بالعربية تلقائياً.
3. **الـ AI ينشئ ملف الأسئلة:** يحفظه داخل `formscript/questions/feature_xyz.txt`.
4. **تشغيل السيرفر:** يشغل `run.bat` أو `npm start`.
5. **أنت تجيب عبر المتصفح:** تختار الإجابات بنقرات سريعة وتضغط **«نسخ النتيجة بالكامل لـ AI»**.
6. **الـ AI يكتب الكود بدقة 100%:** تلصق النتيجة في الشات، ويبدأ العمل بدون أي تخمين أو افتراضات خاطئة.

## 🚀 طريقة التشغيل السريع

### على نظام Windows (موصى به):
انقر نقرتين على:
```cmd
run.bat
```

### عبر موجه الأوامر (Terminal):
```bash
npm install
npm start
```
ثم افتح: **`http://localhost:3000`** في المتصفح.
